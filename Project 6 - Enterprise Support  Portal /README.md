# Enterprise Support Portal

A full-stack web application designed to simulate an Enterprise ERP support ticketing system. This project demonstrates database management, backend routing, and frontend templating.

## Features
- *SQL Database:* Uses SQLite to create, store, and query support tickets.
- *Flask Backend:* Uses Python and Flask to serve dynamic web pages.
- *Jinja Templating:* Dynamically loops through database tuples to generate HTML table rows.
- *Styled Frontend:* Clean, responsive table design using HTML and CSS.

## Technologies Used
- Python 3
- Flask (Web Framework)
- SQLite3 (Database)
- HTML5 & CSS3
- Jinja2 (Templating Engine)

## How to Run
1. Clone the repository.
2. Run python "Database Setup.py" to create and seed the database.
3. Run python app.py to start the Flask server.
4. Open your browser and go to http://127.0.0.1:5000.
